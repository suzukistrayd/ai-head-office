\# INPUT INCOMING - INTAKE AGENT



\## Purpose

Sort everything you dump here into the right place.



\## How to Use

Drop ANY note in this folder. The AI will:

1\. Read it

2\. Identify what it is

3\. Move to correct character/folder

4\. Update knowledge base



\## Types We Accept



| Type | Goes To |

|------|---------|

| Story about Suzuki | characters/suzuki/story.md |

| Story about Martin | characters/martin\_strayd/story.md |

| Mascot idea | mascot\_maker/mascot\_ideas.md |

| Rockstar reference | mentor\_rockstars/rockstar\_references.md |

| Headshot result | promotion\_studio/headshots/results/ |

| Merch idea | promotion\_studio/ecommerce/mockups/ |

| Random thought | inbox.md |

| Affirmation Quotes | mentor\_rockstars/rockstar\_references.md |



\## Trigger Words

\- "story" → Character story folder

\- "mascot" → Mascot Maker

\- "like \[rockstar name]" → Mentor folder

\- "headshot" → Promotion Studio

\- "tshirt" or "merch" → E-commerce

\- "poster" → Editorial Posters

Use Obsidian templates in `INCOMING/templates/`
