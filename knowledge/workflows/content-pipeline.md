# STRAYD — Content Pipeline

## Flow

INPUT/
↓ (dump anything here)
INTAKE AGENT (Dahl sorts)
↓
KNOWLEDGE BASE (organized)
↓
DAHL BRAIN (generates)
↓
DRAFTS (content/drafts/)
↓
APPROVAL (manual review)
↓
OUTPUT/ (social-posts/, images/, captions/)
↓
POSTING (manual or scheduled)


---

## Triggers

| Trigger | Action |
|---------|--------|
| Manual dump in INPUT | Intake agent processes |
| Scheduled (6pm daily) | Generate daily social posts |
| Scheduled (Monday 9am) | Generate weekly content plan |
| Manual workflow_dispatch | Run specific agent |
| GitHub push | Sync to all platforms |

---

## Content Types

| Type | Generated By | Output |
|------|--------------|--------|
| X Post | Dahl | content/drafts/x-YYYY-MM-DD.txt |
| IG Caption | Dahl | content/drafts/ig-YYYY-MM-DD.txt |
| TikTok Script | Dahl | content/drafts/tt-YYYY-MM-DD.txt |
| YT Description | Dahl | content/drafts/yt-template.md |
| FB Post | Dahl | content/drafts/fb-YYYY-WXX.txt |

---

## Approval Workflow

1. Dahl generates drafts → content/drafts/
2. Review in GitHub or dashboard
3. Click [APPROVE] → moves to content/approved/
4. Manual post OR schedule
