\# EDITORIAL POSTER WORKFLOW



\## Purpose

Create magazine-style posters featuring artist/brand.



\## Poster Types

1\. \*\*Artist Poster\*\* - Suzuki or Martin solo

2\. \*\*Band Poster\*\* - STRAYD featuring Martin Strayd \& Suzuki

3\. \*\*Album Poster\*\* - With release info

4\. \*\*Brand Poster\*\* - "Real music. Real people. Real lives."



\## Workflow

1\. Select poster type

2\. Generate with Colab (Diffusion)

3\. Add headline text

4\. Save to `editorial\_posters/templates/`
